Bar colour is sentiment: red negative, green positive, blue neutral.

What This Shows

Start time concerns is both the largest theme (11 responses) and the only negative one. That combination is what makes it the club's next action.
A single average rating would have buried this. Six families praising mentors and eleven complaining about the start time can average out to 'satisfied'. Splitting free text into themes and scoring each one's sentiment separately is what surfaces a specific, fixable problem instead of a number.
