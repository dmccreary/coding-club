# Cytron Maker Pi Pico

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A breakout board for the Raspberry Pi Pico with many built-in features (LEDs, buzzer, and more).

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/maker-pi-pico/](https://dmccreary.github.io/learning-micropython/kits/maker-pi-pico/)  
**Printable one-pager:** [maker-pi-pico-one-pager.html](maker-pi-pico-one-pager.html)

## Features

- Lab: Running lights
- Lab: Micro SD Card Reader

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 2 additional lab pages walk students through the build step by step.
- Budget: $9.99 (board).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller (plugs into the Cytron Maker Pi Pico board)
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
