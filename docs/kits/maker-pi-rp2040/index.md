# Maker Pi RP2040 Robotics Kit

![Maker Pi RP2040 Robotics Kit](maker-pi-rp2040.jpg){ width="420" }

Cytron's single robotics board with motor drivers, NeoPixels, buttons, a buzzer, and Grove ports. It is the controller for the club's low-cost robots.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/maker-pi-rp2040/](https://dmccreary.github.io/learning-micropython/kits/maker-pi-rp2040/)  
**Printable one-pager:** [maker-pi-rp2040-one-pager.html](maker-pi-rp2040-one-pager.html)

## Features

- Power status LED (green)
- On/off switch
- 13 blue LEDs to show status on GP pins 0,1,2,3,4,5,6,16,17,26,27 and 28
- 2 WS2812B RGB LEDs connected to GP18
- LiPo Battery Connector
- Micro USB Port (use for powering and programming)

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 6 additional lab pages walk students through the build step by step.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: $9.90 (board).

## Parts

- **Cytron Maker Pi RP2040 ($10)** — Controller board (built-in RP2040)
- **HC-SR04 Ultrasonic Sensor** — Sensor
- **Momentary Push Buttons** — Input button / switch
- **Piezo Buzzer / Speaker** — Sound output
- **SG90 Micro Servo** — Motor / actuator
- **VL53L0X Time-of-Flight Sensor** — Sensor
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
