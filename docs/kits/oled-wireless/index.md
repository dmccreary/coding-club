# OLED Wireless Weather Kit

![OLED Wireless Weather Kit](oled-wireless.jpg){ width="420" }

An OLED display on a networked Pico that shows the time and weather fetched over WiFi.

**Source book:** Clocks and Watches  
**Kit page:** [https://dmccreary.github.io/clocks-and-watches/kits/oled-wireless/](https://dmccreary.github.io/clocks-and-watches/kits/oled-wireless/)  
**Printable one-pager:** [oled-wireless-one-pager.html](oled-wireless-one-pager.html)

## Features

- See the kit page for details.

## Benefits

- Free, open lessons: the Clocks and Watches textbook has the kit page, wiring, and MicroPython code.
- Budget: about $14 (0.96" OLED about $4.40, Pico W $5, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico W ($5)** — Microcontroller with Wireless
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
