# Wireless STEM Robot

![Wireless STEM Robot](wifi-bot.jpg){ width="420" }

A robot built on the Cytron Robo Pico board with a Raspberry Pi Pico W, so students can drive it over WiFi or Bluetooth.

**Source book:** STEM Robots  
**Kit page:** [https://dmccreary.github.io/stem-robots/kits/wifi-bot/](https://dmccreary.github.io/stem-robots/kits/wifi-bot/)  
**Printable one-pager:** [wifi-bot-one-pager.html](wifi-bot-one-pager.html)

## Features

- Lab: Ping Test
- Lab: Ping Test 2
- Lab: Simple Web Server
- Lab: Web Server Test

## Benefits

- Free, open lessons: the STEM Robots textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 4 additional lab pages walk students through the build step by step.
- Wireless-ready: the Pico W option adds Wi-Fi for time sync and web projects.
- Budget: TBD (a Pico W is about $5; the Cytron Robo Pico board is sold by Cytron and was not found on eBay).

## Parts

- **Raspberry Pi Pico W ($5)** — Microcontroller with Wireless (on Cytron Robo Pico)
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
