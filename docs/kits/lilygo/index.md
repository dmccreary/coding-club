An RP2040 board with a built-in 1.14" 240x135 color LCD (ST7789V) and a high-quality, flicker-free driver.

**Source book:** Clocks and Watches  
**Kit page:** [https://dmccreary.github.io/clocks-and-watches/kits/lilygo/](https://dmccreary.github.io/clocks-and-watches/kits/lilygo/)  
**Printable one-pager:** [lilygo-one-pager.html](lilygo-one-pager.html)

## Features

- Uses the ESP32 Boards
- Uses the Raspberry Pi Pico RP2040
- Uses the ST7789 TFT

## Benefits

- Free, open lessons: the Clocks and Watches textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $11 (board, plus about $3 shipping).

## Parts

- **LILYGO T-Display RP2040** — Microcontroller board with built-in display
- **ST7789 TFT** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
