# Raspberry Pi RGB Box

![Raspberry Pi RGB Box](rgb-box.jpg){ width="420" }

Three knobs, one each for red, green, and blue, mix the color of a NeoPixel strip inside a clear project box.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/rgb-box/](https://dmccreary.github.io/learning-micropython/kits/rgb-box/)  
**Printable one-pager:** [rgb-box-one-pager.html](rgb-box-one-pager.html)

## Features

- How to read a potentiometer with an Analog-to-Digital Converter (ADC).
- How to control NeoPixel LED colors with RGB values.
- How to map a sensor reading to a color value.
- How to build a fun, interactive hardware project.

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Try before you build: an interactive MicroSim on the kit page runs in the browser.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $15 (under $10 when parts are bought in batches of ten).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **10K Potentiometer** — Input knob
- **Single-Color and RGB LEDs** — LEDs
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
