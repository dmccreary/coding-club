# MAX4466 Microphone Kit

!!! note "Photo needed"

A low-cost MAX4466 microphone with a built-in amplifier, wired straight to the Pico's ADC to show sound as an Audacity-style waveform.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/microphone-max4466/](https://dmccreary.github.io/learning-micropython/kits/microphone-max4466/)

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: about $10 (microphone module about $1–$2.70 on eBay; Pico $4, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **MAX4466 Microphone** — Sensor
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
