Clocks built on the MAX7219 chip, which drives a row of seven-segment displays (or an LED matrix) over one serial interface.

**Source book:** Clocks and Watches  
**Kit page:** [https://dmccreary.github.io/clocks-and-watches/kits/max7219/](https://dmccreary.github.io/clocks-and-watches/kits/max7219/)  
**Printable one-pager:** [max7219-one-pager.html](max7219-one-pager.html)

## Features

- Uses the MAX7219 LED Matrix / 7-Segment
- Uses the Raspberry Pi Pico RP2040

## Benefits

- Free, open lessons: the Clocks and Watches textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $10 (8-digit module about $1.45 on eBay; Pico $4, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **MAX7219 LED Matrix / 7-Segment** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
