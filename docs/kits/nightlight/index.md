# Nightlight Circuit Design

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A nightlight circuit using a light-dependent resistor as the sensor, a 2N2222 transistor as the switch, and two potentiometers for adjustment.

**Source book:** Moving Rainbow  
**Kit page:** [https://dmccreary.github.io/moving-rainbow/kits/nightlight/](https://dmccreary.github.io/moving-rainbow/kits/nightlight/)  
**Printable one-pager:** [nightlight-one-pager.html](nightlight-one-pager.html)

## Features

- Uses the 10K Potentiometer
- Uses the LDR Photoresistor

## Benefits

- Free, open lessons: the Moving Rainbow textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: about $4–$6 (estimate: breadboard $2, photoresistor and 2N2222 transistor under $1 together, two potentiometers about $1, an LED and resistors).

## Parts

- **10K Potentiometer** — Input knob
- **LDR Photoresistor** — Sensor
- **830-Point Breadboard ($1.10)** — Breadboard
