*Key part: Cytron Maker Nano RP2040 board (pinout)*

A low-cost, high-function RP2040 board with 14 GPIO LEDs, 2 NeoPixels, a piezo buzzer, and 2 Grove ports.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/maker-nano-rp2040/](https://dmccreary.github.io/learning-micropython/kits/maker-nano-rp2040/)  
**Printable one-pager:** [maker-nano-rp2040-one-pager.html](maker-nano-rp2040-one-pager.html)

## Features

- Low cost: $9
- 14 GPIO blue LEDs
- 2 RGB LEDs (Neopixels)
- 1 Piezo buzzer
- 2 4-wire JST-SH ports (with Grove connectors)

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Budget: $9 (board).

## Parts

- **Cytron Maker Nano RP2040** — Microcontroller board with built-in RP2040
- **Piezo Buzzer / Speaker** — Sound output
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
