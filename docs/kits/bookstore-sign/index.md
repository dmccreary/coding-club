# BookStore Sign

![BookStore Sign](bookstore-sign.jpg){ width="420" }

A 134-pixel NeoPixel sign that spells out the word "Bookstore."

**Source book:** Moving Rainbow  
**Kit page:** [https://dmccreary.github.io/moving-rainbow/kits/bookstore-sign/](https://dmccreary.github.io/moving-rainbow/kits/bookstore-sign/)  
**Printable one-pager:** [bookstore-sign-one-pager.html](bookstore-sign-one-pager.html)

## Features

- Lab: BookStore Sign Programmer's Guide
- Lab: Moving Rainbow Bookstore Sign User Guide

## Benefits

- Free, open lessons: the Moving Rainbow textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 2 additional lab pages walk students through the build step by step.
- Budget: about $16 (estimate: Pico $4, USB cable $2, and about $10 for a 134-pixel strip, based on the $10 144-pixel-per-meter strip in the Cylon Pumpkin).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
