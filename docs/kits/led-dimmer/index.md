# LED Dimmer

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A transistor circuit that dims an LED with a potentiometer, using a 5 V supply, a 2N2222 transistor, and resistors.

**Source book:** Moving Rainbow  
**Kit page:** [https://dmccreary.github.io/moving-rainbow/kits/led-dimmer/](https://dmccreary.github.io/moving-rainbow/kits/led-dimmer/)  
**Printable one-pager:** [led-dimmer-one-pager.html](led-dimmer-one-pager.html)

## Features

- Uses the 10K Potentiometer

## Benefits

- Free, open lessons: the Moving Rainbow textbook has the kit page, wiring, and MicroPython code.
- Try before you build: an interactive MicroSim on the kit page runs in the browser.
- Budget: about $4–$6 (estimate: breadboard $2, 2N2222 transistor, potentiometer, LED and resistors, each under $1).

## Parts

- **10K Potentiometer** — Input knob
- **830-Point Breadboard ($1.10)** — Breadboard
