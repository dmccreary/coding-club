# Bump Switch Bot

![Bump Switch Bot](bump-switch-bot.jpg){ width="420" }

A robot that detects walls with simple microswitches mounted on the front instead of complex sensors, an idea from Dan's friend Michael York. The microswitches cost under $1.

**Source book:** STEM Robots  
**Kit page:** [https://dmccreary.github.io/stem-robots/kits/bump-switch-bot/](https://dmccreary.github.io/stem-robots/kits/bump-switch-bot/)  
**Printable one-pager:** [bump-switch-bot-one-pager.html](bump-switch-bot-one-pager.html)

## Features

- Uses the Bump / Limit Switch
- Uses the Raspberry Pi Pico RP2040

## Benefits

- Free, open lessons: the STEM Robots textbook has the kit page, wiring, and MicroPython code.
- Try before you build: an interactive MicroSim on the kit page runs in the browser.
- Budget: about $20 (base robot $19 plus microswitches under $1).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **Bump / Limit Switch** — Input button / switch
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
