# LED Candle Kit

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A NeoPixel ring that simulates a flickering candle, with a Pico, a breadboard, and either 3 AA batteries or a USB wall adapter.

**Source book:** Moving Rainbow  
**Kit page:** [https://dmccreary.github.io/moving-rainbow/kits/led-candle/](https://dmccreary.github.io/moving-rainbow/kits/led-candle/)  
**Printable one-pager:** [led-candle-one-pager.html](led-candle-one-pager.html)

## Features

- Uses the Raspberry Pi Pico RP2040
- Uses the WS2812B NeoPixels

## Benefits

- Free, open lessons: the Moving Rainbow textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Budget: about $10.

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
