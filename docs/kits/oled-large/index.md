# Large OLED Kit

![Large OLED Kit](oled-large.jpg){ width="420" }

One of the most versatile kits: a bright 128x64 SSD1306 OLED with a Pico W and a DS3231 real-time clock that is accurate to about 2 seconds per month.

**Source book:** Clocks and Watches  
**Kit page:** [https://dmccreary.github.io/clocks-and-watches/kits/oled-large/](https://dmccreary.github.io/clocks-and-watches/kits/oled-large/)  
**Printable one-pager:** [oled-large-one-pager.html](oled-large-one-pager.html)

## Features

- Lab: Blink The Onboard LED
- Lab: Large OLED Assembly
- Lab: Hello World
- Lab: Display Configuration File Data
- Lab: I2C Scanner Test
- Lab: Set RTC form the localtime

## Benefits

- Free, open lessons: the Clocks and Watches textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 18 additional lab pages walk students through the build step by step.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Wireless-ready: the Pico W option adds Wi-Fi for time sync and web projects.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $25 (estimate: 2.42" 128x64 OLED about $13, DS3231 clock about $2, Pico W $5, breadboard $2, wires $1, USB cable $2; about $16 with a 0.96" OLED).

## Parts

- **Raspberry Pi Pico W ($5)** — Microcontroller with Wireless
- **DS1307 RTC** — Real-time clock
- **DS3231 RTC** — Real-time clock
- **Momentary Push Buttons** — Input button / switch
- **SSD1306 128×64 OLED** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
