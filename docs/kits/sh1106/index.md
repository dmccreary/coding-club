# SH1106 OLED Driver Kit

![SH1106 OLED Driver Kit](sh1106.jpg){ width="420" }

A clock that uses the larger 1.3" SH1106 OLED over I2C.

**Source book:** Clocks and Watches  
**Kit page:** [https://dmccreary.github.io/clocks-and-watches/kits/sh1106/](https://dmccreary.github.io/clocks-and-watches/kits/sh1106/)  
**Printable one-pager:** [sh1106-one-pager.html](sh1106-one-pager.html)

## Features

- Uses the SH1106 1.3" OLED

## Benefits

- Free, open lessons: the Clocks and Watches textbook has the kit page, wiring, and MicroPython code.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $15 (1.3" OLED about $4.50, Pico W $5, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **SH1106 1.3" OLED ($2.65)** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
