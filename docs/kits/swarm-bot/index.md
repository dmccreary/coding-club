*Key part: 9-DOF IMU module (store listing)*

A build plan for a heading-follower robot swarm, using the Cytron Robo Pico, a Pico W, and an L3GD20 + LSM303DLHC 9-DOF IMU (the module was purchased for $5.96).

**Source book:** STEM Robots  
**Kit page:** [https://dmccreary.github.io/stem-robots/kits/swarm-bot/](https://dmccreary.github.io/stem-robots/kits/swarm-bot/)  
**Printable one-pager:** [swarm-bot-one-pager.html](swarm-bot-one-pager.html)

## Features

- Uses the TT DC Gear Motors
- Uses the Piezo Buzzer / Speaker
- Uses the Raspberry Pi Pico RP2040
- Uses the Raspberry Pi Pico W / Pico 2 W
- Uses the VL53L0X Time-of-Flight Sensor

## Benefits

- Free, open lessons: the STEM Robots textbook has the kit page, wiring, and MicroPython code.
- Wireless-ready: the Pico W option adds Wi-Fi for time sync and web projects.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: TBD (the IMU module was $5.96 and a Pico W is about $5; the Cytron Robo Pico board was not found on eBay).

## Parts

- **Raspberry Pi Pico W ($5)** — Microcontroller with Wireless (on Cytron Robo Pico)
- **TT DC Gear Motors** — Motor / actuator
- **Piezo Buzzer / Speaker** — Sound output
- **VL53L0X Time-of-Flight Sensor** — Sensor
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
