# Halloween NeoPixel Patterns

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A set of Halloween party patterns for the standard NeoPixel strip and buttons, power-limited for safety, that cycles through patterns automatically.

**Source book:** Moving Rainbow  
**Kit page:** [https://dmccreary.github.io/moving-rainbow/kits/halloween/](https://dmccreary.github.io/moving-rainbow/kits/halloween/)  
**Printable one-pager:** [halloween-one-pager.html](halloween-one-pager.html)

## Features

- Maximum 1/3 pixels lit: Automatically calculates and enforces a limit based on your strip length
- USB-safe: Can be safely powered from USB without external power supply
- Optimized patterns: All effects redesigned to look great within power constraints
- No brightness reduction needed: Pixels can run at full brightness without risk

## Benefits

- Free, open lessons: the Moving Rainbow textbook has the kit page, wiring, and MicroPython code.
- Budget: about $15 (uses the Moving Rainbow base kit).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
