# Adjustabot

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A collision-avoidance robot that students "program" by turning knobs that set motor power (speed), the distance threshold for turning, and the turn time. It suits places without a lab of PCs.

**Source book:** STEM Robots  
**Kit page:** [https://dmccreary.github.io/stem-robots/kits/adjusta-bot/](https://dmccreary.github.io/stem-robots/kits/adjusta-bot/)  
**Printable one-pager:** [adjusta-bot-one-pager.html](adjusta-bot-one-pager.html)

## Features

- Uses the 10K Potentiometer

## Benefits

- Free, open lessons: the STEM Robots textbook has the kit page, wiring, and MicroPython code.
- Budget: about $21 (base robot $19, three potentiometers about $1, a distance sensor about $1).

## Parts

- **10K Potentiometer** — Input knob
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
