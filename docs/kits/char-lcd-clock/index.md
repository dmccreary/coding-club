# Character LCD Clock

![Character LCD Clock](char-lcd-clock.jpg){ width="420" }

A 16x2 LCD1602 character display with a real-time clock that shows the date, time, and temperature.

**Source book:** Clocks and Watches  
**Kit page:** [https://dmccreary.github.io/clocks-and-watches/kits/char-lcd-clock/](https://dmccreary.github.io/clocks-and-watches/kits/char-lcd-clock/)  
**Printable one-pager:** [char-lcd-clock-one-pager.html](char-lcd-clock-one-pager.html)

## Features

- Uses the LCD1602 I2C Character LCD

## Benefits

- Free, open lessons: the Clocks and Watches textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $17 (estimate: LCD1602 with I2C backpack about $5, DS3231 clock about $2, Pico W $5, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **LCD1602 I2C Character LCD** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
