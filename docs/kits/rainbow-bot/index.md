# Rainbow Bot

!!! note "Photo needed"
    We don't have a photo of this kit yet.

The base robot with an 8x8 NeoPixel matrix on top. The colors and patterns change as the robot changes direction.

**Source book:** STEM Robots  
**Kit page:** [https://dmccreary.github.io/stem-robots/kits/rainbow-bot/](https://dmccreary.github.io/stem-robots/kits/rainbow-bot/)  
**Printable one-pager:** [rainbow-bot-one-pager.html](rainbow-bot-one-pager.html)

## Features

- Uses the Raspberry Pi Pico RP2040
- Uses the WS2812B NeoPixels

## Benefits

- Free, open lessons: the STEM Robots textbook has the kit page, wiring, and MicroPython code.
- Budget: about $27–$31 (base robot $19 plus an 8x8 NeoPixel matrix, about $6–$10 on eBay and about $12 on the Moving Rainbow page).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
