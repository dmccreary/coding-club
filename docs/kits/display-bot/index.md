# Display Bot

![Display Bot](display-bot.jpg){ width="420" }

The base robot with a bright 2.42" 128x64 OLED, large enough to read the robot's numbers while standing over it.

**Source book:** STEM Robots  
**Kit page:** [https://dmccreary.github.io/stem-robots/kits/display-bot/](https://dmccreary.github.io/stem-robots/kits/display-bot/)  
**Printable one-pager:** [display-bot-one-pager.html](display-bot-one-pager.html)

## Features

- Lab: Display Distance
- Lab: Display Face
- Lab: Display Setup
- Lab: Time of Flight Display Range Test

## Benefits

- Free, open lessons: the STEM Robots textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 4 additional lab pages walk students through the build step by step.
- Instant feedback: students see their code's results on lights or a display.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: about $32 (base robot $19 plus a 2.42" OLED about $13).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **SG90 Micro Servo** — Motor / actuator
- **SSD1306 128×64 OLED** — Display
- **VL53L0X Time-of-Flight Sensor** — Sensor
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
