A popular 13.56 MHz RFID card reader with strong MicroPython support, wired to a Pico.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/rfid-rc522/](https://dmccreary.github.io/learning-micropython/kits/rfid-rc522/)  
**Printable one-pager:** [rfid-rc522-one-pager.html](rfid-rc522-one-pager.html)

## Features

- Uses the Raspberry Pi Pico RP2040
- Uses the RC522 RFID Reader

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: about $10 (RC522 reader about $1.40–$2 on eBay; Pico $4, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **RC522 RFID Reader** — Sensor
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
