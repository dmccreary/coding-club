# Name Sign Night Light

![Name Sign Night Light](name-sign-night-light.jpg){ width="420" }

A NeoPixel sign spelling a name (the example is "JASON"), with a photo sensor on the back. When the room goes dark it stays lit for 10 minutes, then fades; buttons change the pattern.

**Source book:** Moving Rainbow  
**Kit page:** [https://dmccreary.github.io/moving-rainbow/kits/name-sign-night-light/](https://dmccreary.github.io/moving-rainbow/kits/name-sign-night-light/)  
**Printable one-pager:** [name-sign-night-light-one-pager.html](name-sign-night-light-one-pager.html)

## Features

- All letters are the same color
- The J might be red, A might be blue, S might be green, and so on
- The letters are invisible
- Only one letter lights up

## Benefits

- Free, open lessons: the Moving Rainbow textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Try before you build: an interactive MicroSim on the kit page runs in the browser.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: under $16.

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **Momentary Push Buttons** — Input button / switch
- **LDR Photoresistor** — Sensor
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
