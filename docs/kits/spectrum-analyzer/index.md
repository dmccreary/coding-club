# Spectrum Analyzer Kit

!!! note "Photo needed"
    We don't have a photo of this kit yet.

Reads a microphone through the ADC, runs an FFT, and shows a live frequency spectrum on an OLED. It has since grown into its own book.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/spectrum-analyzer/](https://dmccreary.github.io/learning-micropython/kits/spectrum-analyzer/)  
**Printable one-pager:** [spectrum-analyzer-one-pager.html](spectrum-analyzer-one-pager.html)

## Features

- Uses the Raspberry Pi Pico RP2040

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Budget: about $14 (MAX4466 microphone about $1, 0.96" OLED about $4.40; Pico $4, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
