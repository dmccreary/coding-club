# 8x8 NeoPixel Matrix Project

!!! note "Photo needed"
    We don't have a photo of this kit yet.

An 8x8 panel of 64 RGB pixels, programmed with the NeoPixel library built into MicroPython.

**Source book:** Moving Rainbow  
**Kit page:** [https://dmccreary.github.io/moving-rainbow/kits/8x8-neopixel-matrix/](https://dmccreary.github.io/moving-rainbow/kits/8x8-neopixel-matrix/)  
**Printable one-pager:** [8x8-neopixel-matrix-one-pager.html](8x8-neopixel-matrix-one-pager.html)

## Features

- Uses the WS2812B NeoPixels

## Benefits

- Free, open lessons: the Moving Rainbow textbook has the kit page, wiring, and MicroPython code.
- Budget: about $12 (matrix panel).

## Parts

- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
