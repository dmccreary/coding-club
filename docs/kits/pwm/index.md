# Pulse Width Modulation Kit

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A 9th-grade lesson kit that teaches PWM by dimming an LED with a potentiometer, with an OLED for output.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/pwm/](https://dmccreary.github.io/learning-micropython/kits/pwm/)  
**Printable one-pager:** [pwm-one-pager.html](pwm-one-pager.html)

## Features

- Explain the concept of Pulse Width Modulation (PWM)
- Assemble a basic circuit on a breadboard
- Program a Raspberry Pi Pico microcontroller
- Understand the relationship between duty cycle and LED brightness
- Analyze how PWM is used in everyday technology

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 4 additional lab pages walk students through the build step by step.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Try before you build: an interactive MicroSim on the kit page runs in the browser.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $19 (sum of the listed parts: Pico $4, breadboard $1.75, potentiometer $0.50, LED $0.05, OLED $13).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **10K Potentiometer** — Input knob
- **SG90 Micro Servo** — Motor / actuator
- **Single-Color and RGB LEDs** — LEDs
- **SSD1306 128×64 OLED** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
