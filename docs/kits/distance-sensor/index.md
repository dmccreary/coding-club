# Distance Sensor Box

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A project box pairing a distance sensor with a display. It supports three kinds of distance sensor (binary IR, ultrasonic, and time-of-flight) and two kinds of display.

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/distance-sensor/](https://dmccreary.github.io/learning-micropython/kits/distance-sensor/)  
**Printable one-pager:** [distance-sensor-one-pager.html](distance-sensor-one-pager.html)

## Features

- Uses the HC-SR04 Ultrasonic Sensor
- Uses the VL53L0X Time-of-Flight Sensor

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: about $17 (all three sensors: HC-SR04 about $1, VL53L0X about $2, IR about $1; OLED about $4.40; Pico $4, breadboard $2, wires $1, USB cable $2).

## Parts

- **HC-SR04 Ultrasonic Sensor** — Sensor
- **VL53L0X Time-of-Flight Sensor** — Sensor
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
