# Collision Avoidance Robot

![Collision Avoidance Robot](maker-pi-rp2040-robot.jpg){ width="420" }

A Cytron Maker Pi RP2040 robot with a distance sensor that stops, backs up, and turns before hitting obstacles. It is the robot behind the club's collision-avoidance challenge card (Chapter 18).

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/maker-pi-rp2040-robot/](https://dmccreary.github.io/learning-micropython/kits/maker-pi-rp2040-robot/)  
**Printable one-pager:** [maker-pi-rp2040-robot-one-pager.html](maker-pi-rp2040-robot-one-pager.html)

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 14 additional lab pages walk students through the build step by step.

## Parts

- **Cytron Maker Pi RP2040 ($10)** — Controller board (built-in RP2040)
- **10K Potentiometer** — Input knob
- **TT DC Gear Motors** — Motor / actuator
- **HC-SR04 Ultrasonic Sensor** — Sensor
- **L298N / L293D Motor Driver** — Motor driver
- **MX1508 Motor Driver** — Motor driver
- **Piezo Buzzer / Speaker** — Sound output
- **SG90 Micro Servo** — Motor / actuator
- **SSD1306 128×64 OLED** — Display
- **VL53L0X Time-of-Flight Sensor** — Sensor
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
