# OLED Faces Kit

!!! note "Photo needed"
    We don't have a photo of this kit yet.

Hands-on labs that draw robot faces on a 128x64 OLED with two buttons, covering every MicroPython framebuffer drawing command.

**Source book:** Robot Faces  
**Kit page:** [https://dmccreary.github.io/robot-faces/kits/oled/](https://dmccreary.github.io/robot-faces/kits/oled/)  
**Printable one-pager:** [oled-one-pager.html](oled-one-pager.html)

## Features

- Uses the Momentary Push Buttons
- Uses the Raspberry Pi Pico RP2040
- Uses the Raspberry Pi Pico W / Pico 2 W
- Uses the SSD1306 128×64 OLED

## Benefits

- Free, open lessons: the Robot Faces textbook has the kit page, wiring, and MicroPython code.
- Wireless-ready: the Pico W option adds Wi-Fi for time sync and web projects.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $14 (0.96" OLED about $4.40, two buttons about $0.50; Pico $4, breadboard $2, wires $1, USB cable $2).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **Momentary Push Buttons** — Input button / switch
- **SSD1306 128×64 OLED** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
