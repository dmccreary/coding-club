# NeoPixel Kit

![NeoPixel Kit](learning-micropython-neopixel.jpg){ width="420" }

A low-cost kit used in many of Dan's classes: a Pico, a half-size breadboard, and a WS2812B LED strip (8 to 60 pixels).

**Source book:** Learning MicroPython  
**Kit page:** [https://dmccreary.github.io/learning-micropython/kits/neopixel/](https://dmccreary.github.io/learning-micropython/kits/neopixel/)  
**Printable one-pager:** [learning-micropython-neopixel-one-pager.html](learning-micropython-neopixel-one-pager.html)

## Features

- Lab: Getting Started with the NeoPixel Kit
- Lab: NeoPixel Simple Patterns
- Lab: NeoPixel Button Lab
- Lab: Rotary NeoPixel

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 4 additional lab pages walk students through the build step by step.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: under $10.

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **Momentary Push Buttons** — Input button / switch
- **KY-040 Rotary Encoder** — Input knob
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
