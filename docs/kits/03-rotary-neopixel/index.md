# Rotary NeoPixel

!!! note "Photo needed"
    We don't have a photo of this kit yet.

A rotary encoder and a button control a NeoPixel strip: spin to move the pixel, press the knob to change the color, and press the button to change the pattern.

**Source book:** Learning MicroPython

## Benefits

- Free, open lessons: the Learning MicroPython textbook has the kit page, wiring, and MicroPython code.
- Ready-made curriculum: 5 additional lab pages walk students through the build step by step.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Real-world data: students read sensors and turn measurements into decisions.
- Budget: about $17 (estimate: the $15 Moving Rainbow base parts plus a KY-040 rotary encoder, about $1 on eBay).

## Parts

- **KY-040 Rotary Encoder** — Input knob
- **WS2812B NeoPixels** — LEDs
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
