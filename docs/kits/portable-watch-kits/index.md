# Portable Smartwatch Kits

!!! note "Photo needed"
    We don't have a photo of this kit yet.

Options for making the breadboard smartwatch kits truly wearable. The best fit is the Waveshare ESP32-S3-Touch-LCD-1.28 with onboard LiPo charging.

**Source book:** Clocks and Watches  
**Kit page:** [https://dmccreary.github.io/clocks-and-watches/kits/portable-watch-kits/](https://dmccreary.github.io/clocks-and-watches/kits/portable-watch-kits/)  
**Printable one-pager:** [portable-watch-kits-one-pager.html](portable-watch-kits-one-pager.html)

## Features

- Uses the ESP32 Boards
- Uses the GC9A01 Round TFT
- Uses the Raspberry Pi Pico RP2040

## Benefits

- Free, open lessons: the Clocks and Watches textbook has the kit page, wiring, and MicroPython code.
- Classroom friendly: built on a solderless breadboard or no-solder connectors.
- Instant feedback: students see their code's results on lights or a display.
- Budget: about $15–$20 plus a battery (recommended option).

## Parts

- **Raspberry Pi Pico ($4)** — Microcontroller
- **GC9A01 Round TFT ($3.19)** — Display
- **830-Point Breadboard ($1.10)** — Breadboard
- **Micro-USB Data Cable ($2.50)** — Power and programming cable
