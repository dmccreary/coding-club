What This Shows

The bottleneck is not the same badge in both groups. Tuesday is stuck on Sensors; Thursday is stuck on Debugging. Switch the cohort filter and watch it move.
A dashboard is only useful if it answers a question. This one answers 'where is the cohort stuck', and the answer depends on the group -- the two cohorts have taken different routes through the badge ladder, so they are stuck in different places. That is a signal about what each session has covered, not about the students. Note the underlying mock data holds initials only, the same minimal-identifiability habit the rest of this chapter argues for.
