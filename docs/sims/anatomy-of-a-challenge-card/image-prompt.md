# Anatomy of a Challenge Card — Image Generation Prompt

Please generate a new image.

## Critical Rule

**This image is a deliberate, narrow exception to the usual no-text rule.** The card's OWN printed content is the subject being illustrated, so the following text may appear ON THE CARD: a short project title, a few short materials-list lines, four or five numbered instruction lines, one short stretch-goal line, and one short tag word in a bottom corner. **Nothing else may contain text.** Do not add a poster title, a heading above the card, any callout numbers, any leader lines, any arrows, any annotation marks, or any labels naming the card's parts. The parts are named by an interactive overlay added afterwards, and any naming baked into the image will duplicate and collide with it. Keep the card's own printed words short and generic — they are set dressing, not content to be read.

## Layout Notes

Centre the card with at least 8% clear desk visible on every side. Keep the four printed regions clearly separated by white space so overlay markers can land on each without ambiguity. The stretch-goal box must be visually distinct from the numbered steps -- give it a light tinted background (#F4F0FA) and a thin outline. Keep all printed text on the card small, short, and low-contrast grey so it reads as set dressing rather than something to be studied. Do not tilt or rotate the card. No hands, pens, or other objects in frame.
