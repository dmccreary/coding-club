# References: Designing a Curriculum With Challenge Cards and Portfolios

1. [Project-based learning](https://en.wikipedia.org/wiki/Project-based_learning) - Wikipedia - Explains how organizing instruction around extended projects builds deeper understanding, the model behind this chapter's project-based curriculum tracks.

2. [Pair programming](https://en.wikipedia.org/wiki/Pair_programming) - Wikipedia - Covers the practice of two programmers working together at one workstation, the technique this chapter recommends alongside peer code review.

3. [Code review](https://en.wikipedia.org/wiki/Code_review) - Wikipedia - Explains how developers examine each other's code to catch errors and share knowledge, the practice behind this chapter's peer-code-review activity.

4. Pair Programming Illuminated - Laurie Williams and Robert Kessler - Addison-Wesley - Williams established the academic evidence base for pair programming's effectiveness, the practice this chapter recommends alongside peer code review in its curriculum.

5. Understanding by Design (Expanded 2nd Edition) - Grant Wiggins and Jay McTighe - ASCD - Wiggins and McTighe originated "backward design," planning curriculum from desired outcomes back to activities, the method behind this chapter's beginner-through-advanced pacing guide.

6. [Find a Path](https://projects.raspberrypi.org/en/paths) - Raspberry Pi Foundation - Leveled sequences of coding projects sorted into skill tracks, a working model for this chapter's beginner, intermediate, and advanced curriculum tracks.

7. [Open Badges](https://openbadges.org/) - 1EdTech Consortium - The open standard for verifiable digital skill badges, the technical model behind this chapter's skill-badge system for recognizing student progress.

8. [Scratch](https://scratch.mit.edu) - MIT Scratch Foundation - The project-sharing platform whose gallery of remixable projects models the self-paced learning paths and portfolio-of-student-work concepts in this chapter.

9. [The Station Rotation Model](https://catlintucker.com/2021/10/station-rotation-model/) - Dr. Catlin Tucker - Describes small-group and self-paced station formats that translate directly into this chapter's self-paced learning path and code-along session design.

10. [Start a Club](https://girlswhocode.com/get-involved/start-a-club) - Girls Who Code - Documents how a real club network sequences its own curriculum tracks and project challenges, a working reference for this chapter's curriculum-design guidance.
