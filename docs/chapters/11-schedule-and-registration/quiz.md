#### 1. What is the drop-in model of scheduling?

<div class="upper-alpha" markdown>
1. A schedule that runs for a defined term, then breaks and re-enrolls

</div>

??? question "Show Answer"
    The correct answer is **B**. The chapter defines the drop-in model as having no fixed roster, with the lowest commitment barrier for families but the hardest model to plan mentor capacity for, since attendance is unpredictable session to session. Option A describes the semester-based schedule instead. Option C describes the weekday after-school model. Option D describes the alternating Saturday model, a different fixed-roster approach.
