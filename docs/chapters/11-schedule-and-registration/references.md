# References: Choosing a Schedule and Building Registration

1. [Eventbrite](https://en.wikipedia.org/wiki/Eventbrite) - Wikipedia - History and features of the event registration platform this chapter uses as a case study for building an online sign-up system.

2. [Academic year](https://en.wikipedia.org/wiki/Academic_year) - Wikipedia - Explains how schools structure their calendar around terms and holiday breaks worldwide, the reference point for this chapter's school-calendar-alignment and holiday-scheduling guidance.

3. [Academic term](https://en.wikipedia.org/wiki/Academic_term) - Wikipedia - Compares semester, trimester, and quarter systems, the term structures behind this chapter's semester-based scheduling model.

4. Who Gets What — and Why: The New Economics of Matchmaking and Market Design - Alvin E. Roth - Eamon Dolan/Houghton Mifflin Harcourt - Roth, a Nobel laureate in matching-market design, is credited with the capacity-rationing and priority mechanisms behind this chapter's mentor-gated enrollment strategy, which caps student registration to the number of confirmed mentors.

5. Nonprofit Management 101 (2nd Edition) - Darian Rodriguez Heyman (Editor) - Jossey-Bass - Compiles practitioner guidance on program scheduling models and registration systems appropriate for small volunteer-run organizations, the framework this chapter adapts for choosing a session schedule.

6. [How to Set Up an Event Waitlist](https://www.eventbrite.com/help/en-us/articles/811539/how-to-set-up-an-event-waitlist/) - Eventbrite Help Center - Step-by-step instructions for collecting names once a session is full, directly supporting this chapter's waiting-list-signup guidance.

7. [Change Your Event Capacity](https://www.eventbrite.com/help/en-us/articles/745097/how-to-set-and-restrict-your-events-total-capacity/) - Eventbrite Help Center - Explains the difference between per-ticket quantity and total event capacity, supporting this chapter's registration-capacity-limit section.

8. [Create Forms](https://support.google.com/docs/answer/6281888) - Google Docs Editors Help - Google's own instructions for building, distributing, and collecting responses from an online form, the free tool this chapter recommends for a club's registration form.

9. [Afterschool Alliance](https://afterschoolalliance.org/) - Afterschool Alliance - National data and resources on afterschool program models, supporting this chapter's comparison of alternating-Saturday, weekday, and drop-in scheduling formats.

10. [Start a Club](https://girlswhocode.com/get-involved/start-a-club) - Girls Who Code - Shows how a real coding-club network structures its own application and registration process, a working example for this chapter's registration-system walkthrough.
