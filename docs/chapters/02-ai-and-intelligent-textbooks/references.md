# References: AI, Intelligent Textbooks, and Where Coding Clubs Meet

1. [Artificial intelligence in education](https://en.wikipedia.org/wiki/Artificial_intelligence_in_education) - Wikipedia - Overview of how AI tutoring, content generation, and adaptive systems are being applied to teaching, the trend this chapter connects to coding-club operations.

2. [Generative artificial intelligence](https://en.wikipedia.org/wiki/Generative_artificial_intelligence) - Wikipedia - Explains how generative AI models produce text, images, and code, the underlying technology behind the AI-powered club tools this chapter introduces.

3. [Educational technology](https://en.wikipedia.org/wiki/Educational_technology) - Wikipedia - Broad history of computers and software in teaching, situating intelligent textbooks and interactive simulations within a longer trend of ed-tech adoption.

4. Multimedia Learning (3rd Edition) - Richard E. Mayer - Cambridge University Press - Mayer originated the Cognitive Theory of Multimedia Learning and its "modality" and "multimedia" principles, explaining why pairing text with interactive MicroSims aids comprehension better than text alone.

5. Learning How to Learn - Joseph D. Novak and D. Bob Gowin - Cambridge University Press - Novak invented concept mapping, the visual technique of linking ideas by dependency that underlies the learning graph this chapter presents as an intelligent textbook's backbone.

6. [Five Levels of Intelligent Textbooks](https://dmccreary.medium.com/five-levels-of-intelligent-textbooks-b81a4c1525a0) - Dan McCreary, Medium - The author's own five-level maturity model for interactive textbooks, from static PDF to a book that tracks each student's mastery, matching the framework this book itself follows.

7. [intelligent-textbooks](https://github.com/dmccreary/intelligent-textbooks) - GitHub - Open-source documentation for the MkDocs Material and AI toolchain used to build books like this one, showing how MicroSims and learning graphs are assembled into a page.

8. [Programming Librarian](https://programminglibrarian.org/) - American Library Association - Curated program ideas and webinars for library staff running youth technology programs, directly relevant to the library-hosted club model this chapter surveys.

9. [Khanmigo](https://www.khanmigo.ai/) - Khan Academy - A widely used AI tutoring assistant for K-12 education, illustrating the kind of guided, Socratic AI tool this chapter contrasts with a plain chatbot.

10. [How to Create a Compelling Nonprofit Vision Statement](https://donorbox.org/nonprofit-blog/nonprofit-vision-statement) - Donorbox - A step-by-step guide to drafting mission and vision statements, the exercise this chapter walks readers through for their own club.
