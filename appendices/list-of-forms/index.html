    List of Coding Club Forms¶

    The following is a list of forms that are frequently used by coding clubs.

    1. Student Registration Form¶

    Collect:

    • Student name and preferred name
    • Date of birth, age, and grade
    • School
    • Parent/guardian name
    • Parent/guardian email and phone
    • Student email, if appropriate
    • Emergency contact
    • Accessibility, learning, dietary, or medical considerations
    • Previous coding or robotics experience
    • Device availability
    • Permission to participate
    • Preferred specialty group. Rank 1,2,3:
    • [ ] Scratch
    • [ ] Python
    • [ ] MicroPython
    • [ ] Robots
    • [ ] Advanced Robots
    • [ ] I give the Coding Club permission to use photographs or videos of this student for promotional purposes.
    • Parent/guardian signature and date

    The photograph permission should be optional and separate from permission to participate.

    2. Mentor Registration Form¶

    Collect:

    • Name and contact information
    • Organization or employer, if applicable
    • Emergency contact
    • Relevant education, employment, and volunteer experience
    • Coding and robotics experience
    • Age groups the mentor is comfortable supporting
    • Availability and preferred meeting times
    • Background-check status or consent, where required
    • Code-of-conduct agreement
    • Preferred specialty groups: Rank 1,2,3:
    • [ ] Scratch
    • [ ] Python
    • [ ] MicroPython
    • [ ] Robots
    • [ ] Advanced Robots
    • [ ] I give the Coding Club permission to use photographs or videos of me for promotional purposes.
    • Signature and date

    3. Parent or Guardian Volunteer Form¶

    Collect:

    • Name and contact information
    • Student’s name
    • Emergency contact
    • Volunteer interests:
    • [ ] Check-in and registration
    • [ ] Classroom assistance
    • [ ] Snacks and refreshments
    • [ ] Equipment setup
    • [ ] Event photography
    • [ ] Transportation
    • [ ] Fundraising
    • [ ] Other
    • Availability
    • Relevant skills or certifications
    • Background-check status or consent, where required
    • [ ] I give the Coding Club permission to use photographs or videos of me for promotional purposes.
    • Signature and date

    4. Specialty Group Enrollment Form¶

    Use when students select or change learning groups.

    Collect:

    • Student name
    • Current skill level
    • First and second choices:
    • [ ] Scratch
    • [ ] Python
    • [ ] MicroPython
    • [ ] Robots
    • [ ] Advanced Robots
    • Prerequisite confirmation for advanced groups
    • Learning goals
    • Preferred session
    • Mentor recommendation, if required
    • Parent/guardian approval

    5. Event Registration Form¶

    Collect:

    • Event name and date
    • Student and parent/guardian information
    • Specialty session. Rank 1,2,3:
    • [ ] Scratch
    • [ ] Python
    • [ ] MicroPython
    • [ ] Robots
    • [ ] Advanced Robots
    • Experience level
    • Accessibility, dietary, or medical considerations
    • Emergency contact
    • Equipment the participant will bring
    • Participation consent
    • [ ] I give the Coding Club permission to use photographs or videos of me/my student for promotional purposes.
    • Parent/guardian signature when the participant is a minor

    6. Attendance and Check-In Form¶

    Track:

    • Event or meeting
    • Date
    • Student name
    • Specialty group
    • Check-in time
    • Check-out time
    • Authorized pickup person
    • Mentor or volunteer initials
    • Notes about early departure or attendance issues

    7. Emergency and Medical Information Form¶

    Collect only information the club genuinely needs:

    • Student name
    • Parent/guardian contact details
    • Emergency contacts
    • Allergies
    • Relevant medical conditions
    • Required accommodations
    • Emergency medication instructions
    • Preferred medical provider
    • Authorization for emergency care
    • Parent/guardian signature and date

    Store this form securely with access limited to authorized leaders.

    8. Equipment Checkout Form¶

    Track:

    • Student or mentor name
    • Equipment description
    • Asset or serial number
    • Accessories included
    • Condition at checkout
    • Checkout and expected-return dates
    • Actual return date
    • Condition when returned
    • Borrower agreement
    • Parent/guardian signature for minors

    9. Project Proposal Form¶

    Collect:

    • Student or team names
    • Project title
    • Specialty group:
    • [ ] Scratch
    • [ ] Python
    • [ ] MicroPython
    • [ ] Robots
    • [ ] Advanced Robots
    • Problem or goal
    • Intended users
    • Planned features
    • Hardware and software needed
    • Safety considerations
    • Milestones
    • Mentor
    • Demonstration or presentation plan

    10. Competition or Showcase Entry Form¶

    Collect:

    • Participant or team names
    • Project title
    • Specialty group
    • Project description
    • Hardware and software used
    • Setup and power requirements
    • Internet requirements
    • Accessibility requirements
    • Photo or video permission status for each participant
    • Parent/guardian approval
    • Submission checklist

    11. Incident or Safety Report Form¶

    Collect:

    • Date, time, and location
    • People involved
    • Factual description of the incident
    • Injury or equipment damage
    • Immediate action taken
    • Parent/guardian notification
    • Witnesses
    • Follow-up action
    • Report completed by
    • Leader review

    Keep this form confidential and separate from general attendance records.

    12. Event Feedback and Recommendation Form¶

    Collect:

    • Event name and date
    • Participant role:
    • [ ] Student
    • [ ] Parent or guardian
    • [ ] Mentor
    • [ ] Volunteer
    • [ ] Guest
    • Specialty group attended:
    • [ ] Scratch
    • [ ] Python
    • [ ] MicroPython
    • [ ] Robots
    • [ ] Advanced Robots
    • Overall event rating
    • Ratings for instruction, activities, organization, and facilities
    • Favorite part of the event
    • Suggested improvements
    • Topics desired at future events
    • Permission to contact the respondent about their feedback
    • Optional testimonial
    • Optional permission to publish the testimonial

    Recommendation question¶

    How likely are you to recommend Coding Club events to a friend, classmate, or family member?

    Use a 0–10 scale, where:

    • 0 means “Not at all likely”
    • 10 means “Extremely likely”

    Although a 1–10 scale was requested, standard Net Promoter Score methodology uses 0–10. Using that standard allows the club to classify responses as:

    • Promoters: 9–10
    • Passives: 7–8
    • Detractors: 0–6

    Calculate the report as:

    Net Promoter Score = percentage of promoters − percentage of detractors

    Example: 60% promoters minus 20% detractors produces an NPS of +40.

    Add this follow-up question:

    What is the main reason for the score you selected?
