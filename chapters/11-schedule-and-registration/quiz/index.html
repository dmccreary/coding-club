    Quiz: Choosing a Schedule and Building Registration¶

    Test your understanding of coding club scheduling models and building a mentor-gated registration system that caps enrollment responsibly with these review questions.

    1. What is the drop-in model of scheduling?¶

    1. A schedule that runs for a defined term, then breaks and re-enrolls
    2. A model with no fixed roster, where students attend whichever sessions work for them
    3. A schedule that meets weekly, right after the school day
    4. A schedule that meets every other Saturday, all year
    Show Answer

    The correct answer is B. The chapter defines the drop-in model as having no fixed roster, with the lowest commitment barrier for families but the hardest model to plan mentor capacity for, since attendance is unpredictable session to session. Option A describes the semester-based schedule instead. Option C describes the weekday after-school model. Option D describes the alternating Saturday model, a different fixed-roster approach.

    Concept Tested: Drop In Model See: Drop In Model

    2. What is mentor-gated enrollment?¶

    1. A rule requiring every mentor to be a certified teacher
    2. A policy that closes registration entirely once a club exceeds ten mentors
    3. The system-level rule that student registration capacity is calculated directly from confirmed mentor sign-ups, not set as an arbitrary fixed number
    4. A background-check requirement applied only to gate volunteers
    Show Answer

    The correct answer is C. The chapter defines mentor-gated enrollment as the system-level rule enforcing that student capacity is calculated from confirmed mentor sign-ups rather than an arbitrary number decided months in advance. Option A invents a certification requirement not discussed. Option B fabricates an arbitrary mentor-count cutoff the chapter never states. Option D confuses this with the unrelated volunteer background check process from Chapter 3.

    Concept Tested: Mentor Gated Enrollment See: Mentor Gated Enrollment

    3. What is a registration capacity limit?¶

    1. The maximum number of years a student may remain enrolled
    2. The number of mentors a club is legally allowed to recruit
    3. The total number of sessions offered per calendar year
    4. The maximum number of student sign-ups the registration system allows per session
    Show Answer

    The correct answer is D. The chapter defines a registration capacity limit as the maximum number of student sign-ups the system allows per session, set by mentor availability rather than room size alone. Option A invents an enrollment-duration cap not discussed. Option B confuses this with mentor recruitment, an unrelated legal question. Option C describes a session count, a scheduling detail rather than a capacity limit.

    Concept Tested: Registration Capacity Limit See: Registration Capacity Limit

    4. Why does the chapter say the weekday after-school model is a natural fit for a school-based club but would struggle at a bookstore?¶

    1. Because the model relies on students already being at or near the venue and requires working-hours mentor availability, conditions a school-based club has but a bookstore typically lacks
    2. Because bookstores are legally prohibited from hosting weekday programs
    3. Because weekday after-school scheduling requires a semester-based curriculum track
    4. Because a bookstore's foot traffic is too high for any fixed schedule to work
    Show Answer

    The correct answer is A. The chapter notes the weekday after-school model achieves the highest attendance consistency because students are already at or near the venue, and it requires mentor availability during working hours -- conditions naturally met at a school but not typically at a bookstore. Option B invents a legal prohibition not discussed in the chapter. Option C fabricates a curriculum-track requirement unrelated to scheduling model choice. Option D misapplies the foot-traffic point, which the chapter actually treats as a strength for the drop-in model, not a scheduling obstacle.

    Concept Tested: Weekday After School Model See: Weekday After School Model

    5. Why does the chapter say working around holidays requires more than simply skipping a session when a holiday falls on the schedule?¶

    1. Because skipping a session always violates the club's venue agreement
    2. Because holidays automatically extend a club's semester by two weeks
    3. Because working around holidays only applies to drop-in model clubs
    4. Because an alternating-Saturday club can lose several sessions in a row around late November and December without anyone noticing until it happens, unless the full year's holiday calendar is checked proactively
    Show Answer

    The correct answer is D. The chapter explains that proactively checking a full year's holiday calendar against the scheduling model matters because an alternating-Saturday club can silently lose several consecutive sessions around the winter holidays if nobody checks ahead of time. Option A fabricates a venue-agreement violation the chapter never claims. Option B invents an automatic semester-extension rule not discussed. Option C wrongly restricts the concept to one scheduling model when the chapter applies it generally.

    Concept Tested: Working Around Holidays See: Working Around Holidays

    6. Why does the chapter warn against opening student registration based on how many mentors a club "expects" to confirm, rather than how many actually have confirmed?¶

    1. Because expected mentor counts must be reported to an oversight board first
    2. Because optimistic estimates are how a club ends up over-enrolled before the first session, since actual capacity depends on confirmed, not projected, mentor sign-ups
    3. Because online registration forms cannot process estimated numbers
    4. Because expected mentor counts always underestimate true attendance
    Show Answer

    The correct answer is B. The chapter's warning is explicit: opening student sign-ups based on optimistic mentor estimates rather than confirmed sign-ups is how a club ends up over-enrolled before the first session even happens. Option A invents an oversight-board reporting step not discussed. Option C fabricates a technical limitation of registration forms unrelated to the actual warning. Option D makes an unsupported generalization about estimate accuracy the chapter never claims.

    Concept Tested: Registering Mentors First See: Registering Mentors First

    7. A club has eight confirmed mentors for the upcoming term. Using the chapter's mentor-gated enrollment formula, what is the resulting hard cap on student registration?¶

    1. Eight students
    2. Sixteen students
    3. Twenty-four students
    4. Thirty-two students
    Show Answer

    The correct answer is C. The chapter's own example states that eight confirmed mentors means a hard cap of twenty-four students at the 3:1 ratio, and the registration system should refuse any sign-up beyond that. Option A confuses the mentor count with the student cap itself. Option B applies a 2:1 ratio instead of the recommended 3:1. Option D applies a 4:1 ratio, looser than the chapter's target.

    Concept Tested: Limiting Students By Mentors See: Limiting Students By Mentors

    8. A founding team is launching a club inside a bookstore with heavy walk-in foot traffic and wants the lowest possible commitment barrier for families trying it out for the first time. Which scheduling model does the chapter suggest fits best?¶

    1. Drop-in model, since it works best for high-traffic venues and has the lowest commitment barrier for families to try the club
    2. Semester-based schedule, since it aligns with a school calendar
    3. Weekday after-school model, since it requires the highest attendance consistency
    4. Alternating Saturday model, since it has the longest gap between sessions
    Show Answer

    The correct answer is A. The chapter states the drop-in model has the lowest commitment barrier for families and works best for high-traffic venues like a bookstore or library with heavy walk-in traffic. Option B describes a model tied to a school calendar, a poor fit for a bookstore's walk-in audience. Option C describes a model requiring a captive, consistent student population unlike unpredictable bookstore foot traffic. Option D describes a model with a two-week gap that can weaken momentum, not a strength for this scenario.

    Concept Tested: Drop In Model See: Drop In Model

    9. A club leader opens student registration the moment eight mentors say they are "probably available," without waiting for those mentors to formally confirm specific sessions. Two mentors later drop out before the term starts, leaving the club over-enrolled relative to its actual mentor count. What mistake does this illustrate?¶

    1. The club correctly followed mentor-gated enrollment, since eight mentors were counted before registration opened
    2. The club failed to apply school calendar alignment before publishing its schedule
    3. The club skipped registering mentors first by treating unconfirmed availability as if it were confirmed sign-up, which mentor-gated enrollment specifically guards against
    4. The club's registration capacity limit was set too low rather than too high
    Show Answer

    The correct answer is C. The chapter's warning is precisely this scenario: opening registration on optimistic mentor estimates rather than confirmed sign-ups is how a club ends up over-enrolled, which is exactly what mentor-gated enrollment is designed to prevent. Option A misapplies the concept, since "probably available" is not the same as a confirmed sign-up the chapter requires. Option B confuses this with an unrelated school-calendar scheduling issue. Option D misdiagnoses the problem as a capacity limit set too low, when the actual issue was acting on unconfirmed numbers.

    Concept Tested: Mentor Gated Enrollment See: Mentor Gated Enrollment

    10. A founder is choosing between an alternating-Saturday model and a semester-based schedule for a club that wants to align tightly with defined curriculum tracks and give families a clean, low-pressure exit point every few months, even though it means re-running onboarding at the start of every new term. Which model does this reasoning point to, and why?¶

    1. The alternating Saturday model, because it has the lowest weekly time commitment
    2. The semester-based schedule, because it aligns naturally with school-calendar alignment, gives a clean exit point each term, and suits a curriculum with defined tracks, despite requiring onboarding every term
    3. The drop-in model, because it has no fixed roster to onboard
    4. The weekday after-school model, because it has the highest attendance consistency
    Show Answer

    The correct answer is B. The chapter lists exactly these tradeoffs for the semester-based schedule: it aligns with the school calendar, gives a clean low-pressure exit point each term, suits a curriculum with defined tracks, but requires a full onboarding process at the start of every new term. Option A describes a different model whose tradeoff is a weakened momentum from the two-week gap, not a term-based exit point. Option C misapplies the drop-in model, which has no roster to onboard in the first place. Option D describes a model chosen for attendance consistency, not curriculum alignment or term-based exit points.

    Concept Tested: Semester Based Schedule See: Semester Based Schedule
