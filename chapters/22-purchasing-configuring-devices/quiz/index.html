    Quiz: Purchasing and Configuring Club Devices¶

    Test your understanding of laptop purchasing decisions, platform configuration, student accounts, device lifecycle management, youth safety software, and club Wi-Fi setup with these review questions.

    1. What is the core tradeoff the chapter describes between Chromebooks and Windows or macOS laptops for a club?¶

    1. Chromebooks are always more durable than Windows or macOS laptops
    2. Windows and macOS laptops cannot run Scratch or web-based Python at all
    3. Chromebooks are cheaper and centrally managed but need developer mode enabled for full USB-serial kit access, while Windows and macOS cost more but offer full native support for MicroPython flashing and robot firmware tools
    4. Chromebooks require a paid mobile-device-management subscription, while Windows laptops do not
    Show Answer

    The correct answer is C. The chapter's comparison table shows Chromebooks as cheap and centrally managed but needing developer mode for MicroPython flashing and USB-serial tools, while Windows and macOS cost more but offer full native support for those same tools. Option A overstates durability as an absolute claim the table does not make. Option B contradicts the table, which shows Chromebooks running Scratch and web-based Python well. Option D reverses the actual management relationship, since Chromebooks use a free cloud console while Windows fleets more often need a paid tool.

    Concept Tested: Laptop Purchasing See: Laptop Purchasing

    2. What is a shared device account?¶

    1. A login tied permanently to one specific student, following them across sessions
    2. A single student login used by many different students across different sessions, holding no individual's saved work permanently
    3. The account a club administrator uses to manage the device fleet
    4. A password shared between a student and their parent
    Show Answer

    The correct answer is B. The chapter defines a shared device account as one login used by many students, with no individual's work saved permanently -- files must be moved to a class or cloud folder before the next student sits down. Option A describes an individual device account instead, the opposite account type. Option C confuses this with an administrator account, an unrelated management credential. Option D invents a parent-sharing arrangement the chapter never describes.

    Concept Tested: Shared Device Account See: Shared Device Account

    3. What is a device loaner agreement?¶

    1. A signed form a student or family completes before a laptop leaves club premises, stating responsibility, damage terms, and a return date
    2. A simple sign-out sheet used for tracking a $12 microphone kit
    3. A software tool that blocks distracting websites automatically
    4. The record of every laptop's ID number and purchase date
    Show Answer

    The correct answer is A. The chapter defines a device loaner agreement as a signed form stating who is responsible for a laptop off club premises, what happens if it is lost or damaged, and when it must be returned -- a heavier layer of accountability than a kit's informal sign-out log. Option B describes Chapter 21's kit sign-out process, explicitly contrasted as lighter-weight. Option C describes content filtering software, an unrelated safety tool. Option D describes device inventory tracking, a different record entirely.

    Concept Tested: Device Loaner Agreement See: Device Loaner Agreement

    4. How does parental control software differ from content filtering software?¶

    1. Content filtering software blocks app installation, while parental control software only blocks websites
    2. They are two names for the exact same tool with no functional difference
    3. Content filtering software is configured by families, while parental control software is configured only by the club
    4. Parental control software governs the whole device -- blocking app installation, enforcing time limits, generating usage reports -- while content filtering software specifically blocks website categories
    Show Answer

    The correct answer is D. The chapter's comparison table shows parental control software governing the whole device, including blocking new app installs, while content filtering specifically blocks website categories and does not stop an app installation. Option A reverses which tool blocks app installation. Option B ignores the chapter's explicit table distinguishing the two tools' scope. Option C misstates who configures each tool; the chapter allows either the club or a family to configure parental controls, not content filtering exclusively by families.

    Concept Tested: Parental Control Software See: Parental Control Software

    5. Why does the chapter say a device labeling system matters alongside device inventory tracking?¶

    1. Without a labeling system, the written inventory record and the physical laptops it describes can drift apart silently, since nothing on the shelf shows which laptop matches which spreadsheet row
    2. A labeling system is required before a laptop can connect to Wi-Fi
    3. A labeling system replaces the need for a device loaner agreement
    4. Labeling only matters for laptops that have been repaired at least once
    Show Answer

    The correct answer is A. The chapter explains that without a labeling system, inventory tracking's written record and the physical shelf can drift apart, since the spreadsheet might say "Laptop 7 is in repair" while nothing on the shelf identifies which one is Laptop 7. Option B invents a Wi-Fi connection requirement unrelated to physical labeling. Option C confuses labeling with an unrelated accountability document for off-site loans. Option D fabricates a restriction limiting labeling to repaired laptops only.

    Concept Tested: Device Labeling System See: Device Labeling System

    6. Why does the chapter recommend a separate guest Wi-Fi network for visiting parents and personal devices?¶

    1. Because guest Wi-Fi is required by federal law for any program serving minors
    2. Because personal devices cannot connect to any wireless network without a guest network
    3. Because keeping unmanaged personal devices off the same network the club's laptops depend on prevents them from competing for bandwidth during a session or software update
    4. Because guest Wi-Fi is always faster than the club's own managed network
    Show Answer

    The correct answer is C. The chapter's worked example shows a dozen parent phones on a guest network during an open house, leaving the club's own network free for eighteen laptops running a live demonstration, rather than thirty devices competing for the same bandwidth. Option A invents a federal legal requirement the chapter never states. Option B is factually wrong, since personal devices can connect to any open network, not only a guest one. Option D makes an unsupported speed comparison the chapter never claims.

    Concept Tested: Guest Wifi Access See: Guest Wifi Access

    7. A new club receives a $3,000 grant and plans to buy Chromebooks at $250 each. Using the chapter's worked example, how many Chromebooks can the grant purchase, and how much budget remains?¶

    1. Ten Chromebooks, with $500 remaining
    2. Twelve Chromebooks, with $0 remaining
    3. Six Chromebooks, with $1,500 remaining
    4. Twelve Chromebooks, with $300 remaining
    Show Answer

    The correct answer is B. The chapter's worked example computes exactly this: $3,000 divided by $250 per Chromebook buys twelve devices exactly, one per student in the twelve-student example, with nothing left over. Option A does not match dividing $3,000 by $250. Option C applies the Windows laptop price instead of the Chromebook price to this scenario. Option D confuses this example with the chapter's separate mixed-fleet scenario, which left $300 remaining under different purchase choices.

    Concept Tested: Laptop Purchasing See: Laptop Purchasing

    8. A club laptop has a visibly cracked screen after being dropped. According to the chapter's device repair basics guidance, what should a mentor do?¶

    1. Reseat the battery connection and continue using the laptop as normal
    2. Remove the keycaps and clean debris from underneath before returning it to service
    3. Attempt to replace the screen personally to save on repair costs
    4. Log it in the inventory as "in repair" and send it to the manufacturer or a professional repair shop, since screen replacement is beyond a mentor's safe repair boundary
    Show Answer

    The correct answer is D. The chapter's own worked example addresses this exact scenario: a cracked screen sits outside basic repair boundaries, and the correct response is logging it as "in repair" and sending it to a manufacturer or professional shop rather than attempting the fix. Option A misapplies a battery-reseating fix, an unrelated repair, to a cracked-screen problem. Option B describes fixing a sticking key, a different minor issue entirely. Option C directly contradicts the chapter's warning that attempting a repair beyond the safe boundary risks further damage or a voided warranty.

    Concept Tested: Device Repair Basics See: Device Repair Basics

    9. A club structures its ninety-minute session as twenty-five minutes of Scratch coding, twenty minutes of hands-on kit assembly, twenty-five more minutes of coding, and twenty minutes of unplugged group discussion, deliberately alternating screen work with hands-on activity. Which concept does this session structure illustrate?¶

    1. Screen time management, a session-level practice of alternating coding time with hands-on, unplugged activity rather than a technical device setting
    2. Content filtering software
    3. Device security policy
    4. Password management for kids
    Show Answer

    The correct answer is A. The chapter defines screen time management as a session-level practice, not a device setting, of alternating screen time with unplugged activity -- exactly the four-block structure in this scenario. Option B describes automatic website blocking, a different safety tool. Option C describes device-specific security rules like auto-lock, unrelated to session pacing. Option D describes helping students manage passwords, unrelated to session structure.

    Concept Tested: Screen Time Management See: Screen Time Management

    10. A club with twelve regular, returning students and twelve laptops sets up individual accounts, while a different drop-in club with forty rotating walk-in students and eight laptops uses shared accounts instead. What reasoning does the chapter give for this difference?¶

    1. Individual accounts are always required by law regardless of a club's structure
    2. Shared accounts cost more to set up than individual accounts
    3. The first club's fleet size closely matches its stable roster, making continuity worth the setup, while the second club's forty rotating students could never realistically be matched one-to-one with only eight laptops
    4. Individual accounts are only available on Windows laptops, not Chromebooks
    Show Answer

    The correct answer is C. The chapter's worked example explains that the first club's fleet size closely matches its stable, returning roster, making continuity worth the extra setup, while no single laptop could realistically stay "assigned" to any one of forty different walk-in students in the second club. Option A invents a legal requirement the chapter never mentions. Option B reverses the actual setup cost comparison, since shared accounts are described as simpler to create. Option D fabricates a platform restriction not discussed anywhere in the chapter.

    Concept Tested: Individual Device Account See: Individual Device Account
